# 07. 발표 대본

화면에는 두지 않고 말로 전하는 내용을 파트별로 적는다. 화면 문구를 그대로 읽지 않고, 화면에 없는 연결·안내·강조를 말한다. `06_improvements.md`에서 방향 C(대본에만 반영)로 정한 항목과, A·B에 딸린 대본 작업이 여기에 들어간다.

## 작성 규칙

- 파트 번호와 제목은 `03_outline.md`의 목차와 같게 유지한다. 목차가 바뀌면 이 문서의 제목도 함께 바꾼다.
- 각 파트는 **시간**, **대본**, **화면 조작**(무엇을 누르고 보여 줄지), **출처 메모**(근거가 되는 §, IMP 번호)로 쓴다.
- 대본은 말하는 문장으로 쓴다. 논문에 없는 내용을 말할 때는 "제 생각에는"처럼 리뷰어 의견임을 밝힌다.
- 시간은 목차의 배분을 따르고, 합계가 15분 안팎이 되게 한다.
